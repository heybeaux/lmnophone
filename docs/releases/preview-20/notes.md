# Build 20 — Brightness and Battery

Open **More → Phone settings**.

- **Brightness:** use the slider or − / +. Manual brightness stops at 10%.
  Turn **Adjust automatically** on to let Android adjust it. Manual controls
  are inactive while it is on. **Done** returns to Phone settings.
- **Battery:** see the current percentage and charging state. The page updates
  while open. **‹ Phone settings** returns to the settings list.

Wi-Fi, Bluetooth, Sound and Text size are not in this build. Counts, About,
Home, emergency routes and D1 policy behavior are unchanged. This remains a
preview; pending-change starts, Update and recovery profile remain unwired.

If brightness cannot be changed, the page says so and does not show the requested
value as saved. Unknown battery level is shown as unavailable. The two new error/
unavailable lines carry `TODO(copy)` for the Lead's focused review.
