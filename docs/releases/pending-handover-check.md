# Changes in the next test build

- In PIN settings, **Check this phone** shows whether LMNOPhone is in charge, the approved app list matches, emergency calling components are available, and USB and wireless debugging are off.
- Each check shows OK, what the helper needs to do, or Couldn't check. The page makes no changes and does not open a dialer or place a call.
- Checks that are still unavailable appear under **Not checked yet**. This build does not mark the phone Ready for handover.
- When one opening remains, the opening screens now say **This is your last opening today.** Used-opening counts also use the singular when needed.
