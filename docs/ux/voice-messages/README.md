# Voice-message mockups

All states from [../flows-voice-messages.md](../flows-voice-messages.md), drawn in a browser with the real tokens and Lexend.
Under each phone, "Says" is the spoken text. Sample people only: Sam (a made-up drawing) and Jo (a letter); 555-0100 is fake.

- `voice-messages.html`: the page (open in a browser; uses `../mockups/fonts/`).
- `voice-messages-contact-sheet.png`: the whole page. `png/`: one PNG per state.
- Rebuild: `python3 -I docs/ux/voice-messages/build.py` from the repo root (needs python Playwright with Chromium).

Illustrative only: the build's screenshot tests are the measure of real layout.
