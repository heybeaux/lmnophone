# Plainphone (codename)

An open-source "dumbphone" layer for Android: a calm phone that only runs apps a trusted person has approved, in the spirit of Wisephone/WiseOS.

Status: research + spec phase. No code until Beaux approves the OpenSpec proposal.

- `research/`: DeerFlow deep-research report and notes
- `openspec/`: proposals and specs (created by the team)
