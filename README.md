# Plainphone (codename)

An open-source "dumbphone" layer for Android: a calm phone that only runs apps a trusted person has approved, in the spirit of Wisephone/WiseOS.

Status: research + spec phase. No code until Beaux approves the OpenSpec proposal.

- `research/`: DeerFlow deep-research report and notes
- `openspec/`: proposals and specs (created by the team)
- `site/`: the static landing page (plain HTML and CSS, no tracking). `.github/workflows/pages.yml` publishes it to GitHub Pages on every push to `main`, once a repo admin sets Settings > Pages > Source to "GitHub Actions". The screenshots in `site/screens/` are frames from `docs/ux/mockups/plainphone-screens.html`, rendered at 2x.
